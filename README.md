# Фінальний проєкт: Реляційні бази даних (GoIT)

## Опис проєкту
Цей репозиторій містить фінальний проєкт з курсу "Реляційні бази даних". Метою проєкту була робота з датасетом `infectious_cases`, який містить статистику інфекційних захворювань у різних країнах світу.

## Виконані завдання:
1. **Імпорт даних:** Створено схему `pandemic` у PostgreSQL та завантажено дані з CSV-файлу.
2. **Нормалізація:** Таблицю нормалізовано до 3-ї нормальної форми (3НФ) шляхом винесення атрибутів `Entity` та `Code` в окрему таблицю-довідник.
3. **Аналіз даних:** Написано SQL-запити для розрахунку статистичних показників (середнє, мінімальне, максимальне значення та сума) для захворювання на сказ (`Number_rabies`).
4. **Робота з датами:** За допомогою вбудованих функцій PostgreSQL обчислено різницю в роках між роком запису та поточною датою.
5. **Власні функції:** Створено користувацькі SQL-функції для розрахунку різниці в роках та обчислення середньої кількості захворювань за різні періоди (місяць, квартал, півріччя).

## Стек технологій:
* PostgreSQL
* Python (pandas, SQLAlchemy)
* Google Colab / Jupyter Notebook
